## About

**Elevate Showcase** is the official marketing website for the **Elevate Premium Developer Portfolio Template** by **Dave Digital Studio**.

Rather than being the portfolio template itself, this website is designed to present Elevate as a premium digital product through cinematic layouts, interactive theme previews, device mockups, and modern storytelling.

---

## Features

- Premium product landing page
- Fully responsive across all devices
- Interactive 4-theme switcher
- Editorial & neo-brutalist layout
- Device mockups
- GSAP-powered animations
- Smooth scrolling interactions
- SEO optimized
- Accessibility focused
- Performance optimized
